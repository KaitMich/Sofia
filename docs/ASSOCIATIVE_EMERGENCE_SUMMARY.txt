HOW IT WORKS
================================================================================

SATURATION LOOP:

  1. Calculate Zone Centroid
     - Embed zone keywords (e.g., 'silicon', 'element', 'crystal')
     - Calculate mean → 384-dimensional centroid vector

  2. Process URLs in Zone
     - Fetch URL, extract text
     - Calculate embedding
     - Extract keywords → Count static nouns vs process verbs
     - Extract links

  3. Filter Links by Semantic Distance
     - For each link:
       distance = 1 - cosine_similarity(link, centroid)
       if distance <= allowed_distance:
         → Add to queue (stay in zone)
       else:
         → Log to Event Horizon (forbidden)

  4. Check Phase Transition
     transition_score = (
       (process_verbs / total) * 0.5 +     # Process dominance
       semantic_drift * 0.3 +                # Vector drift
       (event_horizon / 10) * 0.2            # Boundary awareness
     )

     if transition_score >= 0.8:
       → Generate next phase query
       → TRANSITION DETECTED

  5. Save Results
     - Session JSON → autonomous_sessions/
     - Event horizon → future_learning_queue.json
     - Learned content → logic_memory.json

================================================================================
KEY TECHNICAL DETAILS
================================================================================

VECTOR ENGINE:
  - Models: MiniLM-L6-v2 (384-dim) + E5-small-v2 (384-dim)
  - Fusion: Average embeddings when similarity >= 0.7
  - Distance: Cosine distance (1 - similarity)

KEYWORD CLASSIFICATION:
  Static Nouns: rock, stone, mineral, crystal, silicon, atom, element
  Process Verbs: smelt, refine, extract, process, purify, manufacture

PHASE TRANSITION:
  - 50% weight: Process verb ratio
  - 30% weight: Semantic drift from initial zone
  - 20% weight: Event horizon concepts (forbidden)
  - Threshold: Default 0.8 (configurable)

EVENT HORIZON:
  - Tracks concepts seen but not explored (too far from zone)
  - Creates dynamic roadmap for future learning
  - Persisted to: data/future_learning_queue.json

MEMORY STORAGE:
  - All saturation learning → logic_memory (analytical)
  - Metadata → Session JSON files
  - Zone info → Preserved in session data

SECURITY:
  - High-trust domains (>0.8) → Bypass immune/warfare/corroboration
  - Unknown domains → Full security checks
  - Respects robots.txt and rate limits
