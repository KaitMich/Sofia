## 🆕 What's New (December 2025)

### Autonomous Integration - "The Instinct Phase"
The system now operates autonomously with biomimetic sleep cycles and graceful shutdown.

**New Features:**
1. **Value Formation Integration** - Moral values extracted from emotional experiences
2. **Sleep Cycle** - NREM (consolidation) + REM (insight generation) phases
3. **Autonomous Lifecycle** - Continuous operation with 30-minute idle detection
4. **Shutdown Manager** - Graceful signal handling with cleanup registry

**New Documentation:**
- `/docs/AUTONOMOUS_INTEGRATION_COMPLETE.md` - Complete integration guide
- `/docs/DREAM_CYCLE_ARCHITECTURE.md` - Sleep cycle architecture
- `/docs/INITIALIZATION_RUNTIME_SHUTDOWN.md` - **UPDATED** with Part E (Autonomous Lifecycle)
- `/README.md` - **UPDATED** with new features and commands

**New Commands:**
```bash
# Start autonomous mode
python cli.py start --mode autonomous

# Manual sleep cycle
python cli.py sleep-cycle
python cli.py sleep-cycle --nrem-only
python cli.py sleep-cycle --rem-only
python cli.py sleep-cycle --dry-run
```
